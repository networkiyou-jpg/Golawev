## 📌 ما هو GoalWave E2؟

بلوجين مستقل (لا يحتاج أي بلوجين آخر) يحوّل جهاز Enigma2 إلى **مركز مباريات**: نتائج حية، مواعيد، تفاصيل مباريات، وإشعارات أهداف تظهر فوق القناة التي تشاهدها، بتصميم رياضي داكن وأيقونات موحدة.

## ⚡ التثبيت السريع (Telnet / SSH)

انسخ الأمر كسطر واحد في Telnet بحساب root:

```sh
wget -q -O - https://raw.githubusercontent.com/networkiyou-jpg/Golawev/main/install.sh | sh
```

إن كان جهازك بلا `wget`:

```sh
curl -fsSL https://raw.githubusercontent.com/networkiyou-jpg/Golawev/main/install.sh | sh
```

السكربت يحمّل الحزمة، **يتحقق من بصمتها SHA-256** (يرفض أي ملف مختلف)، يزيل النسخة القديمة إن وُجدت (**وتبقى إعداداتك**)، يثبّت، ثم يعيد تشغيل الواجهة. جميع الأوامر الأخرى (إزالة، حالة، سجل…) في ملف [TELNET.txt](TELNET.txt).

> افتح البلوجين من: **Plugins ← GoalWave E2**. لتشغيل/إيقاف الشريط أثناء مشاهدة قناة: الزر الأزرق (Extensions) ← **GoalWave: Toggle Ticker**.

## ✨ المزايا

### 🖥️ اللوحة الرئيسية
- **نافذة بث حي مصغّرة** للقناة التي تشاهدها تظهر في كل الصفحات (تحتاج أن توفر صورة جهازك مصدر الفيديو *VideoPicture*؛ وإلا تظهر نافذة داكنة بدلها).
- **بطاقة القناة الحية:** اسم القناة، البرنامج الجاري، وقته، الدقائق المتبقية، وشريط تقدم — من بيانات الجهاز (EPG) نفسها. لا يُعرض شيء مختلق: إن لم توجد بيانات يظهر "لا توجد بيانات البرنامج".
- صف **شارات/شعارات البطولات** المختارة، ولوحة **المباريات المباشرة** مع شعار كل نادٍ، و**أبرز مباريات اليوم**، و**سجل آخر الأهداف**، و"آخر تحديث" بالثواني الفعلية.

### 📊 شريط النتائج (Ticker) فوق القناة
- وضع **strip** (الافتراضي): **3 مباريات في آن واحد** — شعار البطولة، الدقيقة، شعار واختصار كل ناد، والنتيجة. المباريات المباشرة أولاً وتتحدث مباشرة.
- أوضاع أخرى: **scroll** (نص متحرك) و**page** (مباراة واحدة).
- يمكن التحكم في: المكان (أعلى/أسفل)، الارتفاع، حجم الخط، الألوان، الشفافية، السرعة، إخفاء المنتهية، المباشرة فقط، الترتيب، والتشغيل التلقائي عند الإقلاع (**لا يظهر عند الإقلاع إلا إذا فعّلته**).

### 🥅 إشعارات الأهداف
- إشعار Overlay بشعار الفريق والنتيجة والدقيقة، مع صوت اختياري، ويمكن تفعيل البطاقة الحمراء وبداية/نهاية المباراة.
- **منع الإشعارات الوهمية:** أول تحميل للنتائج، إعادة تشغيل الجهاز، وانقطاع الإنترنت الطويل لا تُنتج إشعارات خاطئة، ولا يتكرر إشعار الهدف نفسه.
- زر **Test Alert** لتجربة الشكل.

### 📅 مركز المباريات
- تبويبات بالأزرار الملونة: **مباشر / اليوم / القادمة / المنتهية**، والتنقل بين الأيام أو إدخال تاريخ محدد.
- **تفاصيل المباراة:** الأحداث (أهداف/بطاقات/تبديلات) والتشكيلة والملعب والقنوات الناقلة — *حسب ما يوفره المصدر* (التفاصيل الكاملة من ESPN).

### 🏆 إدارة الدوريات
- اختيار/إلغاء الدوريات، تحديد الكل، بحث، وحفظ تلقائي. يمكن **إضافة دوري جديد بدون تعديل الكود** (ملف `leagues_user.json`).
- المتوفر: دوري أبطال أوروبا، الدوري الأوروبي، الإنجليزي، الإسباني، الإيطالي، الألماني، الفرنسي، السعودي، كأس العالم، كأس إفريقيا، اليورو.

### 📡 القنوات الناقلة
- قاعدة بيانات **مستقلة** للقنوات/الأقمار/الترددات قابلة للتحديث من رابط أو فلاشة، **فارغة افتراضياً عمداً** (لا يوجد مصدر مجاني موثوق، ولا نخترع ترددات). ما لا يُعرف يظهر "المعلومات غير متوفرة".

### 🧰 أخرى
- واجهة **عربية (RTL)** أو **إنجليزية**، وتتكيف مع **720p / 1080p / 4K**.
- صفحة **حول**: المطور، شعارات البطولات، و**معلومات الجهاز الحقيقية** (الموديل، الصورة، Enigma2، النواة، Python، المعالج، الذاكرة، الفلاش/HDD/USB، IP، مدة التشغيل). أي قيمة لا تُقرأ تظهر "-".
- إعدادات: مصدر البيانات، المنطقة الزمنية (الافتراضي Africa/Casablanca)، فترات التحديث، الكاش، اختبار الاتصال، إعادة الضبط.
- أداء آمن: كل عمليات الشبكة في خيوط خارج الواجهة، ومعالجة للأخطاء، وسجل في `/tmp/goalwave/goalwave.log`.

## 🔌 مصادر البيانات

| المصدر | المفتاح | ملاحظات |
|---|---|---|
| **ESPN** (الافتراضي) | لا يحتاج | واجهة **غير رسمية** وغير موثّقة قد تتغير أو تتوقف |
| **football-data.org** | مفتاح مجاني من الموقع نفسه | رسمي ومستقر؛ الخطة المجانية محدودة الدوريات والطلبات، ولا تعطي الأحداث والتشكيلات |

يمكن التبديل بينهما من **General Settings**. **الدوري المغربي (Botola Pro)** لا مصدر مؤكد له حالياً عند أي منهما.

## ✅ المتطلبات والتوافق

- جهاز بصورة **Enigma2** (Python 2.7 أو Python 3) واتصال إنترنت.
- **طُوّر وجُرّب على OpenATV (Python 3).** مصمَّم لـ OpenPLi / OpenBH / BlackHole / Egami وغيرها **ولم يُختبر عليها بعد**. صور DreamOS أعلى مخاطرة.
- لا تُنقل أي ملفات للمعالج أو ثنائيات: الحزمة `all` (Python فقط).
- صوت الهدف اختياري ويحتاج `aplay` (يُتخطى بصمت إن غاب).

## ❓ الأسئلة الشائعة وحل المشاكل

**لا يظهر البلوجين بعد التثبيت؟** أعد تشغيل الواجهة: `killall -9 enigma2`.

**نافذة البث المصغّرة داكنة؟** صورة جهازك لا توفر *VideoPicture*؛ باقي المزايا تعمل.

**لا تظهر نتائج؟** تأكد من الإنترنت، ومن اختيار دوريات في **Leagues Manager**، ثم جرّب **Test Conn.** في General Settings. إن اخترت football-data.org فتأكد من إدخال المفتاح.

**لا تظهر شعارات الفرق؟** تُحمَّل من الإنترنت وقت التشغيل وتُخزَّن مؤقتاً، وقد تتأخر في أول مرة. شارات البطولات المدمجة تظهر فوراً.

**فشل التثبيت برسالة `checksum mismatch`؟** الملف المحمّل ليس الحزمة الرسمية (مثلاً رابط صفحة بدل رابط الملف الخام). لا تعدّل الملف.

**فشل التحميل بسبب HTTPS؟** صور قديمة لا تتحقق من الشهادات: استخدم `GW_INSECURE=1` كما في [TELNET.txt](TELNET.txt) (يبقى التحقق من البصمة مفعّلاً).

**ظهر كراش أو خطأ؟** أرسل للمطور: صورة الشاشة + ناتج هذا الأمر:

```sh
wget -q -O - https://raw.githubusercontent.com/networkiyou-jpg/Golawev/main/install.sh | sh -s -- status
wget -q -O - https://raw.githubusercontent.com/networkiyou-jpg/Golawev/main/install.sh | sh -s -- log
```

## 🔒 الخصوصية

لا يوجد تتبع ولا إحصاءات. يتصل البلوجين فقط بـ: مزود النتائج الذي اخترته (ESPN أو football-data.org)، ومواقع الشعارات التابعة لهما، ورابط قاعدة القنوات **إن وضعته أنت**. الإعدادات محفوظة محلياً في `/etc/enigma2/goalwave/` والسجل في `/tmp/goalwave/`.

**GoalWave E2** is a standalone Enigma2 plugin for live football: a dashboard with a live TV window and real EPG info for the current channel, a 3-match ticker strip with club and league logos, goal alerts that avoid false alarms (first load, reboot, outages), a match center with details, a leagues manager, a channels database (empty by default; nothing is invented), Arabic (RTL) and English UI, and device info in the About page.

**Install (Telnet/SSH as root):**
```sh
wget -q -O - https://raw.githubusercontent.com/networkiyou-jpg/Golawev/main/install.sh | sh
```
The script verifies the package SHA-256 before installing, keeps your settings on updates, and restarts the GUI. Other commands: `remove`, `purge`, `status`, `log` (see TELNET.txt).

Data: ESPN public (unofficial) or football-data.org (free API key). Developed and tested on OpenATV (Python 3); other images are designed for but not yet tested.
